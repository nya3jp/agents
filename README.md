# agents

コーディングエージェント（Claude Code、Codex、その他 `AGENTS.md` や Agent Skills を読むツール）向けの個人設定。

## 構成

| パス | 読み込まれるタイミング | 用途 |
|---|---|---|
| `AGENTS.md` | 毎セッション（常にコンテキストに入る） | すべてのタスクに適用する中核のルール。短く保つ。 |
| `skills/*/SKILL.md` | `name` と `description` だけが常にコンテキストに入り、本文は必要時に読み込まれる | タスク固有のガイダンス: コミットメッセージ、レビュー、テスト、API 設計、言語のイディオム、Chromium 固有の慣習 |
| `skills/language-style/references/*.md` | 扱っている言語のファイルだけ | 言語ごとのメモ |
| `docs/engineering-profile.md` | 読み込まれない（元資料） | これらのルールの元になった、過去の Gerrit の CL とレビューの分析 |

## インストール

```sh
./install.sh
```

`AGENTS.md` を `~/.claude/CLAUDE.md` と `~/.codex/AGENTS.md` にシンボリックリンクする。各スキルも `~/.claude/skills/`（Claude Code）と `~/.agents/skills/`（Codex）にシンボリックリンクする。既存の通常ファイルは上書きしない。

## メンテナンスの指針

- **言語**
  - プロンプトは日本語で書く。ただしコード、識別子、英語で書かれるべき定型句（コミットメッセージやレビューコメントの例文、ラベル）は英語のまま残す。
  - スキルの `name` は英語のケバブケースにする（ディレクトリ名と一致させる）。
- **`AGENTS.md`**
  - 各行について「これがなければエージェントは間違えるか？」と問い、そうでなければ削除する。
  - モデルがデフォルトでやることは書かない。
  - 200 行を大きく下回るよう保つ。Claude Code はこの上限を推奨しており、Codex はデフォルトで 32 KiB を超えた指示ファイルを切り詰める。
- **新しいガイダンスの置き場所**
  - 複数ステップの手順や、一部のタスクにしか関係しないガイダンスはスキルに入れる。
  - 言語固有の詳細は `skills/language-style/references/` に入れる。
  - Chromium 固有の詳細は `skills/chromium/` に入れ、他の場所には書かない。
- **スキルの description**
  - 三人称で、スキルが何をするかと、いつ使うかを書く。
  - description は読み込みのトリガーであり、毎ターンのコンテキストを消費する。
- **インポート**
  - `AGENTS.md` で `@path` のインポートを使わない。Codex は展開せず、Claude Code はいずれにせよインポート先を即時に読み込む。
- **絶対に破ってはならないルール**
  - 助言的なテキストは無視されることがある。そのようなルールはエージェントの外で強制する（例: `git push` にセキュリティキーのタッチを要求する）。
