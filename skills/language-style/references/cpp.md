# C と C++

- ファイル内でだけ使うシンボルは無名名前空間に置く（または `static` にする）。
- 定義の順序を宣言の順序に合わせる。関数のコメントは宣言の側に置く。
- 不変条件や契約は、プロジェクトの assert の仕組みで検査する。null になり得ないものに null チェックを足さない。null でない引数は参照で受ける。
- `std::make_unique` を使う。引数が複数のコンストラクタに `explicit` を書かない。デストラクタで冗長な `reset()` を呼ばない。
- 所有しないポインタや observer リストのメンバは、それらが指すものを所有するメンバより後に宣言し、破棄順序を正しくする。observer の登録解除は RAII で行う。
- コールバックに生ポインタを束縛するのは、ライフタイムが安全だと証明できる場合だけにする。そうでなければ weak pointer を使う。ただし、呼び出しより長生きするものが何もないなら weak pointer は足さない。
- `#if` は最小限にする。リストを丸ごと複製せず、リストのリテラルの内側でガードする。
- `#else` を伴う否定形の `#if` を避ける。`#else` と `#endif` には条件を注記する。
- ローカルなマクロは使用後に `#undef` する。
- C では、ラッパーで `errno` を保存して復元する。`O_PATH` のファイル記述子はすべてのシステムコールで使えるわけではないことに注意する（`/proc/self/fd/N` を使う）。すべてのシステムコールの結果を確認する。
