# シェル

- コードは shellcheck の警告がない状態に保つ。スクリプトは `#!/bin/bash` と `set -eu`（または `#!/bin/sh -eu`）で始める。
- 必須の変数には `${VAR:?}`、定数には `readonly` を使い、`local` も使う。SC2155 を避ける（コマンド置換の宣言と代入を 1 文で行わない）。
- fork を減らす。ホットパスでは `cat`、`awk`、`grep` のパイプラインより組み込み機能（`compgen`、パラメータ展開）を使う。
- スクリプトが複雑になったら（例: 長い `find` 式）、実行される環境の制約の範囲で、別の言語を検討する。
