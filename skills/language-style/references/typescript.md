# TypeScript

- `parseInt(x)` ではなく `Number(x)` を使う（Google TS スタイル）。
- ファイルシステムの非同期 API を使う。拡張機能ホストで同期 I/O をしない。
- 子プロセスには `...process.env` を継承させ、必要なものだけを上書きする。
- HTML や人間向けの出力をスクレイピングするより、機械可読なエンドポイント（`?format=JSON`）を使う。
- 正規表現は正確に書く。
  - `.` をエスケープする。
  - 仕様どおりの文字クラスを使う。
  - 貪欲マッチによる取りすぎを避ける（例: `".*"` ではなく `"[^"]*"`）。
- コールバックを受け取る代わりに `Promise<T>` を返す。HTTP では 2xx だけを成功とし、それ以外は型付きのエラーを投げる。
- 繰り返し出てくる長い文字列リテラルは定数に括り出す。
